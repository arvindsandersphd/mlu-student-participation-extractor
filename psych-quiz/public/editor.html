    Import a spreadsheet as a new set

    Works with Excel (.xlsx), Google Sheets (download as .xlsx or .csv), and .csv files. Put one question per row in this column order:

    Question · Choice A · Choice B · Choice C · Choice D · Correct (A, B, C, or D) · Seconds (optional)
    A header row is fine. It gets skipped. Download a template to start from.

    In Excel or Google Sheets, select your rows (Question, A, B, C, D, Correct, optional Seconds), copy them, and paste here. You can also type one question per line with commas between parts, like:
    What is the "father of behaviorism"?,Watson,Freud,Rogers,Maslow,A

    Pick an .xlsx or .csv file. The questions are added to the end of this set. Columns: Question, Choice A, Choice B, Choice C, Choice D, Correct (A–D), Seconds (optional). Download a template.

    Click the round button next to the right answer. "Seconds" is optional; leave it blank to use the time you pick when you start the game.
